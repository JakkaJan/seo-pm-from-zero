# КЕЙС 3. Запуск цифрового образовательного продукта (LMS + автоматизация)

**Организация:** ЭБЦ «ЛидерЭКО», Уфа  
**Период:** Февраль — Июль 2025  
**Роль:** Product Manager / IT PM  
**Статус:** ✅ Завершён

---

## Задача
Организация проводила офлайн-обучение. Необходимо запустить цифровой образовательный продукт с автоматизацией регистрации, личных кабинетов, сертификатов и сбора обратной связи.

## Ключевые результаты

| Метрика | Результат |
|---------|-----------|
| Рост бюджета | **+24%** за счёт новых цифровых продаж |
| Процессов задокументировано | **100%** |
| Срок от идеи до MVP | **3 мес.** |
| Пользователей в первый квартал | **500+** |

---

## Что было сделано

### 1. Сбор требований
- 12 стейкхолдеров
- 8 интервью
- Pain points и user stories зафиксированы

### 2. User Flows
- Регистрация → Оплата → Доступ к материалам → Тест → Автоматическая генерация сертификата (PDF)

 
### 3. PRD (Product Requirements Document)


# PRD: LMS «ЛидерЭКО»

## Функциональные требования
| ID | Описание | Приоритет |
|----|----------|-----------|
| FR-001 | Регистрация через Google Forms | Must Have |
| FR-002 | Оплата через платёжный шлюз | Must Have |
| FR-003 | Личный кабинет с прогрессом | Must Have |
| FR-004 | Автогенерация сертификата PDF | Must Have |
| FR-005 | Email-рассылка (welcome, напоминания) | Should Have |


## Нефункциональные требования
- Время отклика =< 2 сек
- Доступность 87%
- Масштабирование на новые регионы без увеличения штата сотрудников
- экономия средств организации
