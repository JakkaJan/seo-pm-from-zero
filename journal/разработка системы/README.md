## Описание

SSHM автоматически сканирует сайты 8 клиентов студии, рассчитывает SEO-score (0–100), расставляет приоритеты P0–P3 и выдаёт:
- цветной консольный отчёт (Rich)
- CSV-файл для Excel
- алерты при обнаружении критических проблем
- delta-сравнение с предыдущим аудитом

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<your-username>/seo-health-monitor.git
cd seo-health-monitor
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate.bat     # Windows

pip install -r requirements.txt
```

**Требования:** Python 3.10+

### 3. Запустить аудит

```bash
python main.py
```

Что произойдёт:
1. Сканируются все 8 сайтов из `data/clients.csv`
2. Результаты сохраняются в `data/monitor.db` (SQLite, создаётся автоматически)
3. В консоли — цветная таблица с метриками и алерты
4. CSV-отчёт сохраняется в `reports/audit_report.csv`
5. Лог записывается в `logs/audit.log`
