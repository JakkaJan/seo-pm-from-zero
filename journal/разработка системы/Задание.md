### 2. Что нужно сделать

#### 2.1 Архитектура решения

Создайте Python-приложение со следующей структурой:


#### 2.2 Функциональные модули

**Модуль scanner.py**
- Функция `scan_site(url: str) -> dict`
- Собирает:
  - `status_code` (HTTP)
  - `title` (текст внутри `<title>`)
  - `title_length` (количество символов)
  - `has_description` (True/False — наличие `<meta name="description">`)
  - `description_length` (если есть)
  - `has_h1` (True/False)
  - `h1_text` (текст H1)
  - `ttfb_ms` (время до первого байта, в мс)
  - `html_size_kb` (размер HTML в KB)
  - `has_ssl` (True/False)
  - `broken_links_count` (количество ссылок со статусом != 200 на главной странице, максимум проверять 20 ссылок)
  - `scan_timestamp` (ISO формат)

**Модуль analyzer.py**
- Функция `calculate_seo_score(scan_result: dict) -> int` (0–100)
  - status_code 200 = 20 баллов
  - title 30–60 символов = 15 баллов
  - has_description + длина 120–160 = 15 баллов
  - has_h1 = 10 баллов
  - ttfb < 1000 мс = 20 баллов, < 3000 = 10 баллов
  - has_ssl = 10 баллов
  - broken_links == 0 = 10 баллов, <= 2 = 5 баллов
- Функция `assign_priority(client_data, previous_audit, current_score) -> str`
  - P0: Премиум + (score < 50 ИЛИ broken_links >= 3 ИЛИ score упал > 10 за месяц)
  - P1: Стандарт + (score < 60 ИЛИ запуск < 6 мес)
  - P2: Базовый + score >= 60
  - P3: Всё остальное

**Модуль database.py**
- Инициализация SQLite таблицы `audits`:
  ```sql
  CREATE TABLE audits (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      client_id TEXT,
      scan_date TEXT,
      status_code INTEGER,
      title TEXT,
      title_length INTEGER,
      has_description BOOLEAN,
      description_length INTEGER,
      has_h1 BOOLEAN,
      h1_text TEXT,
      ttfb_ms REAL,
      html_size_kb REAL,
      has_ssl BOOLEAN,
      broken_links_count INTEGER,
      seo_score INTEGER,
      priority TEXT
  );
  ```
- Функции: `save_audit(data)`, `get_last_audit(client_id)`, `get_all_audits()`

**Модуль reporter.py**
- Функция `generate_console_report(audits: list)` — красивая таблица в консоль (используйте `rich` или `tabulate`)
- Функция `generate_csv_report(audits: list, filename: str)` — CSV для Excel
- Функция `generate_delta_report(current: list, previous: list)` — сравнение с прошлым аудитом

**Модуль notifier.py**
- Функция `check_alerts(audit: dict) -> list` — возвращает список строк с проблемами
  - Пример: "[ALERT] SEO-score упал на 15 пунктов (72 → 57)"
  - Пример: "[ALERT] Обнаружено 5 битых ссылок"
  - Пример: "[ALERT] TTFB 4200 мс (порог 3000 мс)"

#### 2.3 Точка входа (main.py)

```python
# main.py
# 1. Загрузить clients.csv
# 2. Для каждого клиента: scan_site() → calculate_seo_score() → assign_priority()
# 3. Сохранить в SQLite
# 4. Сравнить с audit_history.csv (если есть данные по клиенту)
# 5. Вывести console report + alerts
# 6. Сохранить CSV report
```

### 3. Требования к коду

- Python 3.10+
- Использовать `requests`, `beautifulsoup4`, `pyyaml`, `rich` (или `tabulate`)
- Обработка ошибок: try/except на каждый HTTP-запрос, логирование в `logs/audit.log`
- Таймаут на запросы: 10 секунд
- User-Agent: `Mozilla/5.0 (compatible; DELTA-SEO-Bot/1.0)`
- Не сканировать: mailto:, tel:, javascript:, #anchor
