# Bash: 10 команд, которые я узнал

| Команда | Что делает | Пример |
|---------|-----------|--------|
| `pwd` | Где я сейчас? | `/Users/ivan/Desktop` |
| `ls` | Что в папке? | `file.txt folder` |
| `cd` | Перейти в папку | `cd Documents` |
| `cd ..` | Выйти из папки | |
| `mkdir` | Создать папку | `mkdir new-folder` |
| `touch` | Создать файл | `touch file.md` |
| `cat` | Посмотреть файл | `cat readme.md` |
| `clear` | Очистить экран | |
| `history` | История команд | |

## Моя первая команда (когда буду готов)
Я открою терминал и напишу `pwd`. Увижу свой путь.

## Правило
Пока просто знаю, что эти команды существуют. Терминал — потом.
