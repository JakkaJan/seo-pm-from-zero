# Git: Шпаргалка для себя

## Что я сегодня понял
- Git — это машина времени для файлов
- Commit — это снимок моей работы
- Я могу делать это через сайт, без программ

## Мои 3 команды (пока просто знаю, что они есть)
1. `git add` — подготовить файл
2. `git commit` — сохранить снимок
3. `git push` — отправить на GitHub

## Правило, которое я придумал для себя
Лучше маленький коммит, чем никакого.
