# PRD #3: Миграция сайта на новую CMS с сохранением SEO

## Проблема
Текущая CMS устарела, нет поддержки мобильной версии. Риск потери 30% organic трафика.

## Бизнес-цель
Мигрировать за 6 недель с сохранением 95%+ трафика.

## Stakeholders
| Роль | Интерес | Влияние | Стратегия |
|------|---------|---------|-----------|
| Директор маркетинга | Рост трафика на 10% | Высокое | Еженедельные встречи |
| CTO | Стабильность сервера | Высокое | Технический дайджест |
| SEO-менеджер | Сохранение URL | Среднее | Ежедневный stand-up |
| SEO-агентство | Ссылочная масса | Среднее | Еженедельный отчёт |

## User Stories
| ID | Story | Приоритет |
|----|-------|-----------|
| US-001 | Сохранить структуру URL (301-редиректы) | Must Have |
| US-002 | Перенести все meta-теги | Must Have |
| US-003 | Проверить индексацию в GSC | Must Have |
| US-004 | Запустить на тестовом сервере | Must Have |

## Функциональные требования
| ID | Описание | Критерии приёмки |
|----|----------|------------------|
| FR-001 | 301-редиректы для всех URL | Screaming Frog: 0 ошибок |
| FR-002 | Meta-теги скопированы | 100% совпадение Title/Description |
| FR-003 | Sitemap.xml обновлён | Все URL доступны, 0 404 |
| FR-004 | Robots.txt корректен | Нет блокировки важных страниц |

## Риск-регистр
| ID | Риск | Вероятность | Влияние | План Б |
|----|------|-------------|---------|--------|
| R-001 | Потеря 30% трафика | Средняя | Критичное | Откат на старую CMS |
| R-002 | Пропажа 301-редиректов | Низкая | Критичное | Автопроверка Screaming Frog |
| R-003 | Перегрузка команды | Высокая | Среднее | Фрилансер, урезание scope |

## Таймлайн
| Этап | Неделя | Что делаем |
|------|--------|-----------|
| Подготовка | 1 | Аудит текущего сайта, бэкап |
| Разработка | 2-4 | Новая CMS, редиректы, контент |
| Тестирование | 5 | Тестовый сервер, QA, SEO-проверка |
| Миграция | 6 | Переключение DNS, мониторинг |

## Definition of Done
- [ ] Все URL отвечают 200 или 301
- [ ] Title/Description совпадают на 100%
- [ ] GSC показывает 0 критических ошибок
- [ ] Трафик не упал более чем на 5% за неделю
