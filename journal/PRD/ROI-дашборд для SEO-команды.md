# PRD #4: ROI-дашборд для SEO-команды

## Проблема
Руководство не видит связи между SEO-работами и выручкой. Бюджет сокращают.

## Бизнес-цель
Показать корреляцию CWV → конверсия → выручка. Обосновать бюджет.

## Метрики
| Метрика | Бейслайн | Цель |
|---------|----------|------|
| Конверсия organic | 1.9% | 2.1% |
| Средний LCP | 2.8 сек | &lt;2.0 сек |
| Выручка organic | 500K/мес | 540K/мес |

## User Stories
| ID | Story | Приоритет |
|----|-------|-----------|
| US-001 | Видеть график LCP vs конверсия | Must Have |
| US-002 | Видеть прогнозируемый прирост выручки | Must Have |
| US-003 | Фильтровать по категориям страниц | Should Have |

## Функциональные требования
| ID | Описание | Критерии приёмки |
|----|----------|------------------|
| FR-001 | График корреляции LCP-конверсия | R² &gt; 0.7 |
| FR-002 | Таблица с ROI по каждой странице | CPC, LTV, ROMI |
| FR-003 | Экспорт в PDF для руководства | 1 кнопка, &lt;10 сек |

## SQL-зависимости
```sql
-- Пример запроса для дашборда
SELECT 
    page_url,
    avg_lcp,
    conversion_rate,
    (conversion_rate * 10000) as revenue_forecast
FROM seo_metrics
WHERE date &gt;= CURRENT_DATE - INTERVAL '30 days'
ORDER BY revenue_forecast DESC;
