# User Stories: SEO Site Health Monitor

---

## US-001: Руководитель SEO-отдела
**Как** руководитель SEO-отдела,  
**Я хочу** видеть сводный отчёт по всем клиентам за 5 минут,  
**Чтобы** понимать, где нужно вмешаться до звонка недовольного клиента.

**Критерии приёмки:**
- [ ] Отчёт генерируется командой `python run_audit.py --report`
- [ ] В отчёте есть столбцы: клиент, URL, SEO-score, статус, приоритет
- [ ] Клиенты отсортированы по приоритету (P0 → P3)
- [ ] Цветовая индикация: красный (score < 50), жёлтый (50–70), зелёный (> 70)

---

## US-002: Аккаунт-менеджер
**Как** аккаунт-менеджер,  
**Я хочу** получать список конкретных проблем по моим клиентам,  
**Чтобы** звонить клиенту с готовым решением, а не с вопросом «у вас всё ок?».

**Критерии приёмки:**
- [ ] Для каждого клиента указаны top-3 проблемы с рекомендациями
- [ ] Пример: "Отсутствует Description (добавить 120–160 символов)"
- [ ] Пример: "Битая ссылка /old-page → 404 (настроить 301 редирект)"

---

## US-003: SEO-специалист
**Как** SEO-специалист,  
**Я хочу** сравнивать текущий аудит с прошлым,  
**Чтобы** видеть динамику и доказывать клиенту ценность работы.

**Критерии приёмки:**
- [ ] В отчёте есть столбец "Δ SEO-score" (изменение за месяц)
- [ ] Если score вырос — зелёная стрелка ↑
- [ ] Если score упал — красная стрелка ↓ + причина

---

## US-004: Технический директор
**Как** технический директор,  
**Я хочу** получать систему с документацией и тестами,  
**Чтобы** поддерживать её без автора кода.

**Критерии приёмки:**
- [ ] Код покрыт unit-тестами (pytest) минимум на 60%
- [ ] Есть README.md с инструкцией по запуску
- [ ] Есть requirements.txt
- [ ] Есть config.yaml с примером настроек

---

## US-005: Клиент (косвенный стейкхолдер)
**Как** клиент студии,  
**Я хочу** получать от аккаунт-менеджера проактивные рекомендации,  
**Чтобы** мой сайт не терял позиции из-за технических проблем.

**Критерии приёмки (косвенные):**
- [ ] Аккаунт-менеджер звонит клиенту в течение 48 часов после обнаружения критической ошибки
- [ ] В отчёте для клиента нет технических терминов ("TTFB" → "скорость загрузки")

---

*Приоритет: US-001 > US-002 > US-003 > US-004 > US-005*
